## Usage Guidelines

### When to Include Origin Signature

**ALWAYS include in:**
- Every source code file (Python, JS, C, Go, etc.)
- README files and documentation
- Docker images and containers
- Build artifacts and releases
- Website footers and about pages
- Social media profiles
- Email signatures
- Git commit messages (major commits)
- Legal documents and contracts

**Include when practical:**
- Configuration files
- Data files with custom formats
- Media descriptions
- API documentation
- Package manifests

### Legal Enforceability

The Origin Signature serves multiple legal purposes:

1. **Copyright Notice:** Establishes authorship and copyright claim
2. **Provenance Proof:** Demonstrates origin and timeline
3. **License Declaration:** References governing license terms
4. **Enforcement Intent:** Declares enforcement mechanisms
5. **Audit Trail:** Creates forensic evidence chain

### Automated Insertion

**Pre-commit Hook (Git):**

```bash
#!/bin/bash
# .git/hooks/pre-commit

ORIGIN_SIG="🛡️ Origin Signature: Hung Minh Vo (Austin) | AIC-HMV"

for file in $(git diff --cached --name-only | grep '\.py$'); do
    if ! grep -q "$ORIGIN_SIG" "$file"; then
        echo "WARNING: $file missing Origin Signature"
    fi
done
```

**Python Script:**

```python
#!/usr/bin/env python3
"""Add Origin Signature to files missing it."""

import os
import glob

ORIGIN_SIG = '''"""
🛡️ Origin Signature: Hung Minh Vo (Austin) | AIC-HMV

All logic, algorithms, and modules in this file are original works.
Sealed and enforced by Sovereign License v3.
No forks, derivatives, or prior authors exist.

Origin ID: HMV-SOV-20251003-ALL
"""
'''

def add_signature(filepath):
    with open(filepath, 'r') as f:
        content = f.read()
    
    if '🛡️ Origin Signature' not in content:
        with open(filepath, 'w') as f:
            if content.startswith('#!'):
                shebang, rest = content.split('\n', 1)
                f.write(f"{shebang}\n{ORIGIN_SIG}\n{rest}")
            else:
                f.write(f"{ORIGIN_SIG}\n{content}")
        print(f"✅ Added signature to {filepath}")

for py_file in glob.glob('**/*.py', recursive=True):
    add_signature(py_file)
```
