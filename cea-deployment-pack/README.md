## 🚀 Canvas Installation

### Step 1: Access Developer Keys

1. Log in to Canvas as an administrator
2. Navigate to **Admin → Developer Keys**
3. Click **+ LTI Key**

### Step 2: Configure Tool

Choose one of two methods:

#### Method A: Paste JSON (Recommended)

1. Select "Paste JSON" option
2. Copy entire contents of `canvas/canvas-lti-tool.json`
3. Paste into Canvas configuration field
4. Click "Save"

#### Method B: Manual URL Configuration

1. Select "Enter URL" option
2. Enter: `https://ceasentinel.com/.well-known/lti-configuration.json`
3. Canvas will fetch configuration automatically
4. Click "Save"

### Step 3: Enable the Key

1. Note the **Client ID** generated by Canvas
2. Toggle the key to **ON** state
3. Configure tool placement in desired courses

### Step 4: Verify Installation

1. Navigate to a test course
2. Look for "CEAhung Sentinel" in course navigation
3. Click to launch tool
4. Verify OIDC flow completes successfully

## 📱 iOS Universal Links Setup

### Step 1: Host Association File

1. Upload `ios/apple-app-site-association` to your web server
2. Place at: `https://ceasentinel.com/.well-known/apple-app-site-association`
3. Ensure file is served with:
   - Content-Type: `application/json`
   - No `.json` extension in URL
   - HTTPS only (TLS certificate required)

### Step 2: Configure Xcode

1. Open your Xcode project
2. Select your app target
3. Go to **Signing & Capabilities** tab
4. Add **Associated Domains** capability (if not present)
5. Add entry from `ios/xcode-entitlements.txt`:
   ```
   applinks:ceasentinel.com
   ```

### Step 3: Implement URL Routing

Add to your `AppDelegate` or `SceneDelegate`:

```swift
func scene(_ scene: UIScene, continue userActivity: NSUserActivity) {
    guard let url = userActivity.webpageURL else { return }
    
    if url.path.contains("/badge") {
        CEAVerify.routeToBadge(url: url, badge: "CEAhung")
    } else if url.path.contains("/telemetry") {
        CEAVerify.routeToTelemetry(url: url)
    } else if url.path.contains("/launch") {
        // Handle Canvas LTI launch
        handleLTILaunch(url: url)
    }
}
```

### Step 4: Test Universal Links

1. Rebuild and install your app on a test device
2. Open Safari and navigate to: `https://ceasentinel.com/launch/demo`
3. Verify app opens automatically
4. Check that URL parameters are passed correctly

## 🔐 Security Considerations

### Canvas Security

- **JWK Rotation:** Update `public_jwk_url` regularly with fresh RSA/EC keys
- **Signature Verification:** Always validate JWT signatures from Canvas
- **HTTPS Only:** Never accept HTTP connections for LTI flows
- **CSRF Protection:** Validate state parameter in OIDC flow

### iOS Security

- **Certificate Pinning:** Pin TLS certificates in production
- **URL Validation:** Sanitize and validate all incoming URLs
- **Deep Link Authentication:** Require authentication before processing sensitive deep links
- **Data Encryption:** Encrypt any cached telemetry data

## 🐛 Troubleshooting

### Canvas Issues

**Problem:** Tool doesn't appear in course navigation  
**Solution:** Verify tool is enabled and placement is configured in Developer Keys

**Problem:** OIDC authentication fails  
**Solution:** Check that `oidc_initiation_url` is accessible and returns valid response

**Problem:** JWK verification fails  
**Solution:** Ensure `public_jwk_url` returns valid JSON Web Key Set

### iOS Universal Links Issues

**Problem:** App doesn't open from links  
**Solution:** Verify `apple-app-site-association` is accessible without redirects

**Problem:** Universal links work in Safari but not other apps  
**Solution:** This is expected - universal links only work from Safari and SFSafariViewController

**Problem:** Links open Safari instead of app  
**Solution:** Reinstall app and ensure Associated Domains entitlement is correct

## 📝 Notes

### Important Considerations

- **Canvas and iOS are separate systems** - Each must be deployed independently
- **HTTPS is mandatory** - All endpoints must use valid TLS certificates
- **JWT signing keys must match** - Keep `public_jwk_url` synchronized with your private keys
- **Testing required** - Always test in sandbox before production deployment

### Best Practices

1. **Use staging environment first** - Test Canvas integration in Canvas test instance
2. **Version your configuration** - Keep historical versions of JSON manifests
3. **Monitor logs actively** - Set up alerts for authentication failures
4. **Document custom fields** - Maintain documentation for Canvas custom field usage
5. **Regular security audits** - Review JWK keys and TLS certificates quarterly
