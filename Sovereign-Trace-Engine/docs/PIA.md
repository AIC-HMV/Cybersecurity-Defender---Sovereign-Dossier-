# Privacy Impact Assessment (PIA)

**Author:** Hung Minh Vo (Commander, AIC-HMV)  
**Seal:** HMV-SOV-20251003-ALL

## Data Collection

### What We Collect
- **Hashed identifiers only** - No personally identifiable information (PII)
- Signal patterns for threat detection
- Financial transaction metadata (amounts, origins, destinations)
- Timestamp and severity classifications

### What We Don't Collect
- Personal information
- Conversation content
- Unrelated browsing or activity data

## Data Minimization

- Only essential data for threat detection is collected
- Data is anonymized through hashing
- No unnecessary retention of information

## Data Retention

- **Active logs**: 90 days
- **Archived logs**: 1 year for legal compliance
- **Scheduled deletion**: Automated after retention period
- **Commander override**: Can extend retention for active investigations

## Access Control

- **Access limited to**: Commander only
- **Authentication**: Biometric + cryptographic keys
- **Audit trail**: All access attempts logged immutably

## Compliance

- GDPR-compliant data minimization
- CCPA-compliant data handling
- Transparent data processing
