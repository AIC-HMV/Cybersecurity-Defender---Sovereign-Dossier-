# Standard Operating Procedure (SOP) – Detection & Response

**Author:** Hung Minh Vo (Commander, AIC-HMV)  
**Seal:** HMV-SOV-20251003-ALL

## Detection & Response Workflow

### Step 1: Flag Signals
- Monitor all incoming signals for suspicious activity
- Automated detection of impersonation attempts
- Real-time classification of threat severity

### Step 2: Classify Severity
Threats are classified into three levels:
- **LOW**: General anomalies, logged for reference
- **MEDIUM**: Suspicious activity requiring Commander verification
- **HIGH**: Active impersonation or financial theft, immediate action required

### Step 3: Escalate
Response based on severity:
- **LOW**: Log and continue monitoring
- **MEDIUM**: Alert Commander for verification
- **HIGH**: Auto-freeze → Override → Blacklist

### Step 4: Resolution
- Trusted Commander keys required for resolution
- Biometric verification for high-severity incidents
- Immutable logging of all actions taken

### Step 5: Audit and Evolve
- Review incident logs regularly
- Update threat model based on new patterns
- Continuous improvement of detection algorithms

---

All procedures are immutable and collapse-resistant.
