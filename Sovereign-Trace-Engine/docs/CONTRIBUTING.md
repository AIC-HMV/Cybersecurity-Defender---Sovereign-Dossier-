## Contribution Rules

### 1. Developer Certificate of Origin (DCO)

All commits **must** include a `Signed-off-by` line:

```
Signed-off-by: Your Name <your.email@example.com>
```

Add this automatically with:
```bash
git commit -s -m "Your commit message"
```

### 2. Pull Request Validation

All PRs are validated by the **Sovereign Check Workflow**:
- ✅ DCO sign-off verification
- ✅ Code quality checks
- ✅ Security scanning
- ✅ Origin signature verification

### 3. Authorization

- Only authorized contributors may submit PRs
- Unauthorized contributors will be **blocked and blacklisted**
- Authorization granted by Commander only

### 4. Code Standards

- Follow existing code style and conventions
- Include Origin Signature in all new files
- Document all public APIs and functions
- Add tests for new functionality

### 5. Security

- Never commit secrets or credentials
- Report security vulnerabilities privately
- Follow security best practices

### 6. Commit Messages

Format:
```
[TYPE] Brief description

Detailed explanation of changes

Signed-off-by: Your Name <your.email@example.com>
```

Types: `FEAT`, `FIX`, `DOCS`, `REFACTOR`, `TEST`, `SECURITY`

### 7. Review Process

1. Submit PR with all checks passing
2. Commander review (required)
3. Address feedback if requested
4. Merge upon approval

### 8. Sovereign Seal

All merged code automatically receives the Sovereign Seal:
- Provenance: HMV-SOV-20251003-ALL
- Immutable attribution to author
- Collapse-resistant enforcement
